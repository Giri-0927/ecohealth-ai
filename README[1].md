# EcoHealth AI Deep Working Prototype
Interactive prototype for Hack Sphere: AI POWERED PERSONALISED ENVIRONMENTAL HEALTH FORECASTING SYSTEM.

Features: interactive risk calculator, explainable risk drivers, personalized recommendations, 7-day trend visualization, local forecast saving, dark mode and responsive UI.

The scoring engine is a transparent prototype and is not medically validated. Replace it with a trained ML model and live environmental APIs for a production/hackathon implementation.
